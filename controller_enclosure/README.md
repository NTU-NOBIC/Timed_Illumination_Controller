# Controller Enclosure — 3D CAD Model

This folder contains a 3D CAD model for the enclosure associated with the **Timed Illumination Controller** project.

| File | Description |
| --- | --- |
| [`Illum_driver_enclosure_v1b.step`](./Illum_driver_enclosure_v1b.step) | Controller enclosure geometry in STEP format (version `v1b`). |

## Viewing and Using the Model

1. Download `Illum_driver_enclosure_v1b.step`.
2. Open or import it in a CAD application that supports STEP files (for example, FreeCAD, Autodesk Fusion, or SOLIDWORKS).
3. Inspect the geometry, dimensions, clearances, and fit against your hardware before manufacturing.
4. If required, export the model to a manufacturing format such as STL for 3D-printing preparation.

## File Information

- **Format:** STEP (`.step`), a neutral 3D CAD exchange format.
- **STEP schema:** AP214 (`AUTOMOTIVE_DESIGN`).
- **Model geometry:** The uploaded file contains two named solid bodies, `Body1` and `Body3`.
- **Version:** `v1b` (from the filename).

> **Note:** Material, print orientation, manufacturing tolerances, hardware compatibility, and assembly instructions are not specified in the STEP file. Verify these before fabrication.
